# 5. Held-out programs are written blind and run once

Ten programs per set, written from a one-page brief and the supported-operations list by someone
who has not seen the compiler, each with traps where sizes matter. The first full run of a
held-out set is recorded and never rewritten. Set v1 was seen failing (a quick run picked it up
while it was being written) and fixed against, so it became a regression set and v2 was written
afterwards by a new writer.
